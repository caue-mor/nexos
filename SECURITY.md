# Security Policy

## Reporting a vulnerability

Do not open a public issue for a security vulnerability.

Report it through GitHub's private vulnerability reporting for this repository:

https://github.com/caue-mor/nexos/security/advisories/new

This opens a private draft advisory visible only to maintainers until a fix
is ready. It requires "Private vulnerability reporting" to be enabled for
this repository (Settings → Security → Advisories) — if the link above
refuses to open a draft, that toggle is off; contact a maintainer through
another channel instead.

## Supported versions

Only the latest published version on npm receives security fixes.

## What to include

- Affected version
- Reproduction steps or a minimal example
- Impact (what an attacker gains)

## What NOT to include

Never paste a live credential, token, or secret into a report — describe
where it was found and its variable/pattern name instead.
